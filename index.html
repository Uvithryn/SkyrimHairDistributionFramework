Instructions

This tool makes it easy to generate SPID files to be used with Hair Distribution Framework. Just select NPCs, assign hairstyles to them, and download the SPID distribution file. As long as you have Hair Distribution Framework, SPID, and the right wigs installed, you'll see the new hairstyles on NPCs once the SPID file's in your Skyrim Data folder. Once you've selected hairstyles, you'll see a hyperlinked list of the required wigs at the top of the page, just above the Instructions button. This list updates dynamically based on the hairstyles selected.

1 · Add NPCs

Each row contains one NPC. You can add rows with the Add row button at the bottom of the list (set the ×N box to add several at once). In an empty row, you can:

  • Search Skyrim's vanilla and DLC NPCs by name or EditorID. Results show as Name (EditorID).
  • ＋ Add a new NPC for one not in the list: enter its EditorID, name, race, and gender.
  • Import CSV (top left) to add many at once. Columns: EditorID, Name, Race, Gender, Vanilla Hair ID (EditorID is the only required one). Known EditorIDs pull in bundled data automatically; the rest come in as custom. These CSV files can be generated with the xEdit scripts found on Hair Distribution Framework's Nexus mod page.

2 · Assign a hairstyle

Every row starts with the NPC's vanilla hairstyle if one is available, and you can use the dropdown to override it. The list is filtered to styles valid for that NPC's race and gender. The preview image on the right shows you what that hairstyle looks like on the NPC's race type (Human/Elf/Orc/Khajiit/Argonian) and gender. If a modded NPC doesn't have a recognized race, you'll see the human version of the preview. You can resize previews with the Preview size menu at the top.
To browse through pictures of the available hairstyles, click on Hairstyle Browser. The haistyle browser can be filtered based on race type and gender.

3 · Unsupported cases

Unrecognized vanilla hairstyles are flagged and written into the output commented out, so they never break your file. If a CSV race isn't recognized, the row opens all hairstyles and shows a small selector so you can set a race yourself.

4 · Saving your work

  • Save project downloads a .json file you own. You can upload that file again later with the Load project button to pick up where you left off. This file is your real backup.
  • The tool also auto-saves in this browser after every change, so you won't lose work if you accidentally close the tab. The auto-save lives in browser storage and can be wiped by clearing browsing data, so download a save file for anything you want to keep.
  • New project clears everything and starts fresh.

5 · Get the output

Click on the Distribution output drawer at the bottom of the page to open it. Download the _DISTR.ini file, or copy the text. Any files in Skyrim's data folder that end with _DISTR.ini will be read by SPID, so once you put it in your data folder, you should see those hairstyles on those NPCs next time you open Skyrim up. If you're publishing any SPID files, you'll want them in the root of your zip file.
